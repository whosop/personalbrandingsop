# 🌸 Website Personal Branding - Shofiyatul Nur Ghilbah

Website personal branding dengan desain modern dan warna pastel yang menampilkan profil, keahlian, portfolio, dan CV.

## ✨ Fitur

- **Homepage (Beranda)** - Halaman utama dengan foto profil, tagline, dan deskripsi diri
- **About Me (Tentang Saya)** - Informasi lengkap tentang riwayat keluarga, pendidikan, hobi, minat, cita-cita, dan kelebihan diri
- **Skills (Keahlian)** - Tampilan skill dengan progress bar dan circular progress
- **Portfolio (Karya/Proyek)** - Showcase dari 3 proyek yang telah dikerjakan
- **CV (Curriculum Vitae)** - CV lengkap dengan format profesional

## 🎨 Desain

- **Tema**: Modern & Minimalis
- **Warna**: Pastel (Pink, Purple, Blue, Yellow, Green)
- **Font**: Poppins & Playfair Display
- **Responsif**: Mobile, Tablet, Desktop

## 🚀 Cara Menggunakan

1. Download semua file
2. Pastikan struktur folder seperti ini:
   ```
   ├── index.html
   ├── about.html
   ├── skills.html
   ├── portfolio.html
   ├── cv.html
   ├── style.css
   ├── script.js
   └── README.md
   ```
3. Buka `index.html` di browser

## 📱 Halaman Website

### 1. Homepage (index.html)
- Hero section dengan foto profil
- Tagline: "just me, improving every day."
- Quick intro cards
- Animasi background shapes

### 2. About Me (about.html)
- Foto profil dengan badge
- Riwayat keluarga
- Timeline pendidikan
- Hobi dan minat
- Cita-cita
- Soft skills & hard skills

### 3. Skills (skills.html)
- Skill bars dengan animasi:
  - HTML: 40%
  - CSS: 40%
  - JavaScript: 30%
  - Cisco Packet Tracer: 60%
  - Editing (Canva): 75%
  - Word, Excel, PowerPoint: 85%
- Circular progress indicators

### 4. Portfolio (portfolio.html)
- **Desain Mug** - Desain mug dengan konsep artis favorit
- **Website Kelompok** - Game journal & review website
- **Microsite Shop** - Toko digital berbasis S.id

### 5. CV (cv.html)
- Layout 2 kolom (sidebar + main content)
- Foto profesional
- Data pribadi & kontak
- Pendidikan timeline
- Pengalaman (Lomba, Organisasi, PKL)
- Skills dengan progress bar
- Quote motivasi
